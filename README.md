# Call Center Management System – Design Patterns in Practice

## Overview

This project demonstrates the design and implementation of a Call Center Management System built using C# Windows Forms, with a strong focus on applying software design patterns to solve real-world communication and call-handling challenges in a structured and scalable way.

The system is designed for a student-focused call center where both students and call center technicians can initiate, receive, and manage calls. All call activity is stored in a virtual call log, enabling managers to track, search, and return calls efficiently.

---

## System Features

- Make and receive calls through a desktop-based interface  
- Store calls in a centralized virtual call log  
- Search and navigate through call records  
- Return calls directly from the call log  
- Manage call states in real time  

---

## Call Lifecycle States

Each call can transition through different states:

- Active Call – users can communicate, and call duration is recorded  
- On Hold – communication is paused, and duration tracking is suspended  
- Ended (Hung Up) – call is terminated and stored in the call log

## Design Patterns Implemented

This project applies multiple software design patterns to improve maintainability, scalability, and code organization:

- State Pattern  
- Command Pattern  
- Observer Pattern  
- Singleton Pattern  
- Strategy Pattern
